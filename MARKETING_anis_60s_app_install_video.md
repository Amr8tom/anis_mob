# Anis — 60-second App-Install Video (production-ready package)

**Goal:** downloads. **Platforms:** TikTok / Instagram Reels / YouTube Shorts. **Audience:** Egyptian students (16–25). **Voice:** warm, youthful, Egyptian Arabic. **Tagline:** ذاكر مع ناس، مش لوحدك.

## Trend rules this video follows (2026)
- Win the **first 3 seconds** — show the payoff immediately, no logo intro.
- **Show the app in use** (live screen recording / over-the-shoulder), not screenshots — this is the single biggest install driver.
- **Text overlay ≤ 7 words**, restates/escalates the audio (for silent viewers + the algorithm).
- **UGC / native look** beats polished ads: phone-shot, natural light, talk to camera.
- Target **~35–45s** (shorter retains better); 60s is the cap, not the target.
- Make **3 hook variants** and rotate; UGC creatives fatigue in ~1 week.

# THE 3 HOOK CUTS (full, shot-by-shot — body is shared)

Each hook = the first **0:00–0:03**. After 0:03 all three continue with the shared body from the script table above (app demo → real space → buddy → streak → CTA).

### Hook A — Problem ("the lonely studier")
- **Visual:** student alone at night, closed books, scrolling, yawning.
- **On-screen (≤7 words):** بتذاكر لوحدك ومملّ؟
- **VO:** "لسه بتذاكر لوحدك في البيت؟"
- *Best for:* cold audiences who feel the pain. Usually the lowest CPI.

### Hook B — Outcome ("the result first")
- **Visual:** open on the live app screen — streak counter jumping, "ساعات المذاكرة" rising fast.
- **On-screen:** اللي بيذاكر هنا بيخلّص أسرع
- **VO:** "الطلاب اللي بيذاكروا على أنيس بيخلّصوا أسرع — بصّ."
- *Best for:* outcome-driven students; strong for retargeting.

### Hook C — Curiosity / pattern-interrupt
- **Visual:** hand flips phone around, fast whip-pan into the map of nearby spaces.
- **On-screen:** في مكان مذاكرة جنبك 👀
- **VO:** "تعرف إن في مكان مذاكرة على بعد دقائق منك دلوقتي؟"
- *Best for:* broad reach; the QR/map reveal is the curiosity payoff.

### Hook D — Value ("one pass, every place")
- **Visual:** same QR scanning into 3 different spaces, "اشتراك واحد" badge pulsing.
- **On-screen:** اشتراك واحد… كل الأماكن
- **VO:** "اشتراك واحد بس… وتدخل بيه أي مكان مذاكرة معانا."
- *Best for:* price-conscious students; strong value angle, great for retargeting.

> Rule: keep the body identical across A/B/C so you isolate which *hook* wins. Kill the two losers within ~3–4 days, scale the winner, then make 2 fresh hooks.

# AD CAMPAIGN BRIEF (run this to actually get the installs)

**Objective:** App installs (optimize for "Install", not views or clicks).

**Platforms / budget split (start small, scale the winner):**
- TikTok — 50% (cheapest installs for this audience).
- Instagram/Facebook Reels — 35%.
- YouTube Shorts — 15%.

**Destination:** the app-store listing via a campaign/attribution link, so a tap goes straight to download and you can see which creative drove the install.

**Audiences:**
- Geo: Egypt (start with Cairo/Giza/Alex if budget is tight).
- Age 16–25; interests: studying, exams (الثانوية العامة), university, productivity, coworking/cafés.
- Add a **lookalike** of installers once you have ~100+ installs.
- **Retargeting:** people who watched ≥50% of any video but didn't install → run Hook B (outcome).

**Creatives:** the 3 hook cuts as 3 separate ads in one ad group; let the platform allocate to the winner. Refresh weekly (UGC fatigues ~7 days).

**Daily budget:** start ~$10–20/day/platform for 4–5 days to gather signal, then move 70% of budget to the lowest cost-per-install creative.

**KPIs to watch:** Cost Per Install (CPI), Install Rate (installs ÷ clicks), 3-sec view rate (hook strength), and Day-1 retention from the store/analytics. If CPI rises >30% over 2 days, the creative is fatiguing — rotate.

**Measurement:** put a unique campaign link per platform; if you can, add an attribution SDK (or use the store's campaign URLs) so installs map back to the exact hook.
