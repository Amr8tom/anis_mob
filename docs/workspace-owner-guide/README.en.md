# Workspace Owner Dashboard Quick Guide

This guide is intentionally simple. Each section explains what the page is for, when to use it, and the basic steps.

## Quick Start

1. Open the workspace owner portal.
2. Sign in with your phone number and password.
3. Use the sidebar to move between pages.
4. General pages appear first: **Daily Attendance**, **Visitors**, and **Sessions**.
5. Workspace-specific pages appear below: **Education Management**, **Private Sessions**, **Private Subscriptions**, **Room Reservations**, **Notifications**, and **Settings**.

## 1. Daily Attendance

![Daily attendance](screenshots/daily-attendance.png)

**Purpose:** Check visitors in and out during the day.

**Use this page to:**
- Register a visitor quickly by phone and name.
- See who is inside now.
- Check a visitor out and calculate visit duration.
- Review recently finished visits.

**How to use:**
1. Enter the phone number.
2. Enter the name if the visitor is new.
3. Select **Check in**.
4. When the visitor leaves, check them out from the active visitors table.

## 2. Visitors

![Visitors](screenshots/visitors.png)

**Purpose:** Search visitor history and review visit totals.

**Use this page to:**
- Search by visitor name or phone number.
- Filter by date or plan.
- Review visits, minutes, and estimated revenue.

**How to use:**
1. Enter a name or phone number.
2. Choose a date range or plan if needed.
3. Select **Apply**.
4. Open **View history** for a specific visitor.

## 3. Sessions

![Sessions](screenshots/sessions.png)

**Purpose:** Manage public sessions that can appear in the mobile app.

**Use this page to:**
- Add a public study session or workshop.
- Set the host, time, and price.
- Edit or delete existing sessions.

**How to use:**
1. Select **Add new session**.
2. Enter the session details.
3. Set the start and end time.
4. Save and review it in the table.

## 4. Education Management

![Education management](screenshots/education-management.png)

**Purpose:** Prepare workspace-only education data: teachers, subjects, and grade levels.

**Use this page to:**
- Add teachers or instructors.
- Add subjects such as Arabic, English, or Math.
- Add grade levels.
- Reuse this data in private sessions and filters.

**How to use:**
1. Add teachers.
2. Add subjects.
3. Add grade levels.
4. Use **Disable** to hide an item without deleting it.

## 5. Private Sessions

![Private sessions](screenshots/private-sessions.png)

**Purpose:** Manage workspace-only sessions that are not public for all app users.

**Use this page to:**
- Create a private class or group.
- Track registered and attended visitors.
- Calculate revenue and instructor payout.
- Open the management and QR check-in pages.

**How to use:**
1. Select **Create private session**.
2. Open **Manage** after creation.
3. Add attendees manually or import a file.
4. Use QR check-in or manual attendance.
5. Select **Finish session** when it is done.

## 6. Create Private Session

![Create private session](screenshots/private-session-create.png)

**Purpose:** Create a private session with all needed setup details.

**Use this page to set:**
- Title and description.
- Host or teacher.
- Subject and grade level.
- Price per attendee.
- Instructor payout type and value.
- Start time, end time, and capacity.

**How to use:**
1. Enter the title.
2. Add a short description if needed.
3. Choose education data if this is a class.
4. Set price and instructor payout.
5. Set schedule and capacity.
6. Select **Create session**.

## 7. Private Subscriptions

![Private subscriptions](screenshots/subscriptions.png)

**Purpose:** Create workspace-only plans and issue subscriptions to visitors.

**Use this page to:**
- Create plans with hours, days, and price.
- Issue a subscription to a walk-in visitor.
- Track active subscriptions.
- Cancel subscriptions when needed.
- Manage activation codes.

**How to use:**
1. Create a plan.
2. Choose or enter the visitor phone number.
3. Issue the subscription.
4. Track remaining hours and days in the issued subscriptions table.

## 8. Room Reservations

![Room reservations](screenshots/rooms.png)

**Purpose:** Manage rooms and prevent reservation conflicts.

**Use this page to:**
- Add rooms.
- Reserve a room for a client.
- Choose date and time.
- Add notes.
- Cancel a reservation if needed.

**How to use:**
1. Add the available rooms.
2. Enter client details.
3. Choose room and time.
4. Save the reservation.
5. Review current and upcoming reservations.

## 9. Notifications

![Notifications](screenshots/notifications.png)

**Purpose:** Send notifications to registered app users connected to the workspace.

**Use this page to:**
- Notify all registered workspace visitors.
- Notify selected users.
- Notify public or private session attendees.
- Use templates.
- Preview reachable users before sending.

**How to use:**
1. Choose the audience.
2. Choose a template or write a title and message.
3. Choose the notification language.
4. Select **Preview audience**.
5. Review counts, then select **Send notification**.

## 10. Settings

![Settings](screenshots/settings.png)

**Purpose:** Update workspace profile, appearance, and operating settings.

**Use this page to:**
- Edit name, description, and contact details.
- Update location.
- Upload photos.
- Select amenities.
- Set visitor checkout mode.
- Change language or theme.

**How to use:**
1. Open the needed settings section.
2. Edit the data.
3. Review your changes.
4. Select **Save all changes**.

## Quick Tips

- Use **Daily Attendance** for daily front-desk work.
- Use **Visitors** for history and reporting.
- Use **Private Sessions** for internal classes or groups.
- Set up **Education Management** first if the workspace is an education center.
- Always use **Preview audience** before sending notifications.
- Use **Finish session** when the session happened. Use **Cancel session** only if it did not happen.
